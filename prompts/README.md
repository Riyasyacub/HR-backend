# Prompt Log

This folder keeps a record of the prompts used while building this project.

## Files

- `prompt-log.md` — chronological log of prompts, newest entries at the bottom.

## Format

Each entry uses a dated section, then the prompt text verbatim in a blockquote:

```markdown
## YYYY-MM-DD

### Short title

> The exact prompt text.

Notes (optional): what was done, files touched, follow-ups.
```

Keep prompts verbatim when possible; add context in a short note underneath so the
reasoning behind each change stays traceable.
